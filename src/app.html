    Gemini AI (무료)

    API 키를 넣으면 단어마다 예문 추가, 뉘앙스 설명, 질문하기를 앱 안에서 바로 볼 수 있어요. 키가 없으면 질문을 복사해서 Gemini 앱으로 넘겨 드려요.

    키 받는 법: aistudio.google.com/apikey 에서 Google 계정으로 로그인 → 「Create API key」 → 복사.

    키는 이 휴대폰 브라우저에만 저장되고, 질문할 때 Google로만 보내져요.

    진도 백업

    휴대폰을 바꾸거나 브라우저 데이터를 지우기 전에 진도를 복사해 두세요.

    학습 기록이 모두 지워져요. 되돌릴 수 없어요.

    앱으로 설치

    안드로이드 Chrome: 오른쪽 위 메뉴(⋮) → 「홈 화면에 추가」 또는 「앱 설치」. 아이폰 Safari: 공유 버튼 → 「홈 화면에 추가」.
